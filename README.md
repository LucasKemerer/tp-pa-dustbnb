# dustbnb - Panel de Administración 🧹

Primer Trabajo Práctico de desarrollo backend y frontend para la gestión de un sistema de reservas (parodia/homenaje a Airbnb), enfocado en la validación y autenticación de usuarios.

## 📋 Descripción del Proyecto
Este proyecto consiste en el desarrollo de la interfaz inicial y la lógica de autenticación para el panel de administración de **dustbnb**. El objetivo principal es aplicar los conceptos de maquetado web, validación del lado del cliente y procesamiento de formularios en el servidor.

## 🛠️ Tecnologías Utilizadas
* **Backend:** PHP (Procesamiento de login y estructura de plantillas).
* **Frontend:** HTML5, CSS3 (Framework: Bootstrap 5).
* **Interactividad:** JavaScript (Validación de DOM nativo).

## ✨ Requerimientos (TP1)
* Estructura de directorios organizada (`/css`, `/js`, `/img`, `/includes`).
* Sistema de plantillas con cabecera (`header.php`) y pie de página (`footer.php`).
* Formulario de Login (usuario y contraseña) maquetado con Bootstrap.
* Validación del lado del cliente con JavaScript (Habilitación dinámica del botón submit).
* Script `procesoLogin.php` para la validación estricta de credenciales en el servidor.

## 🚀 Instalación y Ejecución
1. Clonar este repositorio o descargar el código fuente.
2. Mover la carpeta del proyecto al directorio público de tu servidor local (ej: `htdocs` en XAMPP o `www` en WAMP).
3. Iniciar el servicio de Apache.
4. Acceder desde el navegador a: `http://localhost/nombre-de-tu-carpeta/index.php`
